# 礼尚往来

一款用于记录婚礼、满月、乔迁等酒席人情往来的轻量级礼品礼金记账系统。采用 PHP + MySQL，无需 Composer 或前端构建，上传到 PHP 空间后通过网页安装向导即可使用。

## 功能特性

- **分活动记账**：每场酒席独立成册，记录姓名、关系、金额、币种、礼品、日期、地址、备注等信息。
- **自定义字段**：支持新增、编辑、删除字段，拖拽调整列顺序，并设置字段类型、是否显示及是否必填。
- **还礼建议**：根据当年收礼金额、日期和年均通胀率，复利折算当前参考价值，展示建议金额与计算过程。
- **多币种与汇率**：内置常用币种，支持手动维护汇率，也可通过 open.er-api.com 免费接口联网更新。
- **简繁英切换**：界面支持简体、繁体和 English，记录内容可随界面进行简繁字形转换。
- **数据导出与备份**：按活动或全部记录导出 CSV（带 UTF-8 BOM，可直接用 Excel/WPS 打开），支持完整 JSON 备份。
- **暗色响应式界面**：Cloudflare 风格暗色主题与橙色点缀，适配桌面和手机。
- **安全存储**：管理员密码单向哈希存储，数据库操作使用 PDO 预处理，前端输出统一转义。

## 技术栈

- 后端：PHP 7.4+、PDO、MySQL 5.7+（推荐 MySQL 8.0+）
- 前端：原生 HTML / CSS / JavaScript，无构建步骤
- 繁简转换：opencc-js（已包含在项目中，可离线使用）
- 可选本地环境：Docker Compose

## 快速安装

### 上传到 PHP 空间

环境需开启 `pdo_mysql` 和 `mbstring` 扩展。

1. 将项目文件上传到网站根目录，并确保该目录可写。
2. 使用浏览器访问站点，系统会在未安装时自动进入安装向导。
3. 填写数据库主机、数据库名、用户名和密码，并设置管理员密码。
4. 点击“开始安装”，程序会自动创建数据库、数据表和 `config.php`。
5. 安装完成后，使用刚设置的管理员密码登录。

安装成功后，建议删除或重命名 `install.php`。`config.php` 包含数据库凭据，已被 `.gitignore` 排除，不应提交到公开仓库。

### Docker 本地预览

在项目根目录执行：

```bash
docker compose -p lishang up -d --build
```

打开 <http://localhost:8099>，在安装向导中填写：

- 数据库主机：`db`
- 数据库名：`lishang`
- 数据库用户名：`root`
- 数据库密码：`root123`
- 管理员密码：自行设置

停止预览：

```bash
docker compose -p lishang down
```

如需同时清空本地预览数据：

```bash
docker compose -p lishang down -v
```

## 基本使用

1. 在“办酒记录”中新建活动，例如“婚礼”“宝宝满月”。
2. 进入活动，点击“添加记录”登记来宾、金额或礼品等信息。
3. 如需调整表格结构，进入“字段设置”，拖拽排序或新增自定义字段。
4. 点击记录行的还礼建议按钮，查看按通胀率折算的参考金额。
5. 在活动页导出单场 CSV，或在“设置”中导出全部 CSV 与 JSON 备份。

## 目录结构

```text
├── index.php              # 应用入口
├── install.php            # 网页安装向导
├── login.php              # 登录页
├── logout.php             # 退出登录
├── api/                   # 活动、字段、记录、设置、导出等接口
├── includes/              # 配置、数据库、鉴权及内置建表 DDL
├── assets/
│   ├── css/style.css      # 界面样式
│   └── js/                # SPA、多语言与繁简转换
├── Dockerfile             # 可选 Docker 预览环境
├── docker-compose.yml
└── README.md
```

`config.php` 在安装后自动生成，不属于版本控制内容。

## 安全提示

- Apache 环境下，项目自带 `.htaccess` 限制对 `config.php`、`includes/` 等敏感路径的 Web 访问。
- Nginx 不会读取 `.htaccess`，请在服务器配置中增加相应访问限制。
- 请为管理员和数据库使用独立强密码，并定期下载 JSON 备份。
